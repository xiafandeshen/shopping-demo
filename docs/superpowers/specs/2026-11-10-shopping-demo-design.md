# 购物网站设计

## 目标与范围

实现可本地运行的购物网站演示闭环：商品浏览与搜索、详情与评价、演示登录、购物车、地址管理、确认订单、支付、订单列表和订单详情。AI 购物助手按钮保留但暂不实现交互。商品图暂用占位图；示例商品 P001 作为初始种子数据。

## 技术架构

- 前端：React 19、TypeScript、Vite 8、shadcn/ui、Tailwind CSS 4、Zustand 5、React Router DOM 7、Axios、TanStack Query 5、React Hook Form 与 Zod 4。
- 后端：FastAPI、SQLAlchemy 2.0、SQLite，Python 3.11+；数据库创建和种子数据初始化由后端负责。
- 前端通过 `/api/` 调用后端。开发环境使用 Vite 代理转发 API；生产部署拓扑不属于本阶段范围。

## 页面与交互

### 共享区域

所有页面使用登录状态栏。未登录时可打开登录弹窗，使用固定演示账号登录；已登录时显示欢迎信息、“我的订单”和“退出”。购物车浮动入口在首页、搜索、商品详情等购物页面复用。购物车弹窗展示空态、商品行、选中状态、数量调整、移除和确认订单操作。加购提供短暂动画与结果反馈。

### 商品浏览

首页按推荐分数降序展示前 20 个商品；搜索结果页保留搜索词，每页 20 个商品并支持分页。搜索按钮仅在有有效搜索词时导航。商品组件展示图片/占位图、名称、描述、价格及加入购物车按钮；无库存时显示“已售完”。图片和名称进入商品详情。详情页展示商品大图、名称、描述、品牌、类别、特性、价格及评价。

### 订单流程

确认订单页要求用户选择已有收货地址；没有地址时先提供新增地址表单，也允许从地址列表添加。页面展示选中商品与数量、商品金额、优惠和运费。满 1000 减 100；AI 来源订单在其他优惠后再打 95 折；订单满 999 免运费，否则运费 100。下单时保存商品名称、单价、数量、优惠与运费快照，避免商品后续变化影响历史订单。

支付页根据订单状态展示付款或关闭结果。待付款订单可完成演示支付并转为已付款待发货，订单关闭状态显示提示并在 3 秒后回首页。我的订单和订单详情页共享状态操作规则：待付款可取消；已付款待发货取消需提示退款说明；已发货可申请退货或确认收货；退货中可取消退货并回到已发货；其余终态提供查看详情。

## 数据模型

- `users`：演示用户身份、显示名称及登录标识。
- `products`：商品基本信息、价格、库存、毛利率、推荐分、规格 JSON、图片地址、上下架状态。
- `reviews`：商品评价、用户显示名、评分、内容及创建时间。
- `addresses`：用户收货人、电话、地区、详细地址及默认标记。
- `cart_items`：用户商品数量及选择状态。
- `inventory_locks`：用户、商品、锁定数量、状态和过期时间，为未来真实锁库保留记录。
- `orders`：用户、地址快照、订单来源、状态、商品总额、优惠总额、运费、应付金额及时间字段。
- `order_items`：订单商品名称、图片、单价和数量快照。

购物车加购及数量增加均调用库存锁定接口；当前后端全部成功，并沿用明确的库存不足错误响应结构。订单状态使用稳定的英文枚举值，API 和界面映射为中文标签。关键外键、唯一约束、非负数量/金额校验及用户订单查询索引在建表时定义。

## API 边界

- 商品：推荐列表、分页搜索、商品详情（含规格与评价）。
- 会话：演示登录、当前用户、退出。
- 地址：当前用户地址列表、新增地址。
- 购物车：读取、添加/调整数量（库存锁定）、选择状态、移除。
- 订单：从选中购物车项创建待付款订单、订单列表/详情、状态动作、演示支付。

订单创建和支付等写操作验证用户所有权及当前状态；重复支付或不允许的状态迁移返回清晰错误。未登录访问购物车结算与订单接口时返回未授权响应。当前演示认证机制不承诺生产级安全性。

## 错误处理与验证

前端异步操作均显示加载和错误状态；空购物车、无搜索结果、无订单及无地址均提供明确空态或下一步入口。表单由 React Hook Form 与 Zod 校验。后端测试覆盖商品种子数据、搜索分页、演示登录、购物车数量、地址和订单金额规则、状态迁移及支付；前端测试覆盖关键可复用组件和流程状态。最终运行后端测试、前端测试、lint 与生产构建。

## 排除项

真实账号注册、密码找回、第三方支付、真实库存扣减/并发锁定、AI 助手交互、商品图片素材采购、生产部署和物流对接不在本阶段范围内。
