# AI 助手新开对话设计

## 目标

支持用户创建全新的 AI 助手对话。旧对话记录保留在数据库中，但界面仅显示当前最新对话。

## 方案

为助手会话增加稳定的会话 ID。读取、发送消息均可指定会话 ID；未指定时兼容选择用户最近会话。新增创建会话接口，创建空会话并返回其 ID 与消息列表。前端在助手打开时加载当前会话，点击“新开对话”并确认后调用创建接口，切换当前会话并清空界面消息。

## 交互

标题栏增加“新开对话”按钮。点击后显示确认提示；确认创建新会话，取消保持当前内容。创建失败时保留原消息并显示错误。

## 数据与兼容性

历史 AssistantConversation 记录不删除。现有订单、购物车、支付链接不受影响。未携带会话 ID 的旧客户端继续使用最近会话。

## 验证

覆盖创建会话、按会话读取和发送消息使用指定会话，以及前端确认取消和成功切换场景。
